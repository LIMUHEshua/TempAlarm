# Changelog

All notable changes to this project will be documented in this file.

## [v0.1.0] - 2026-10-02

### Added
- Initial project version
- DHT11 temperature and humidity reading support
- BH1750 ambient light reading support
- ST7735S display support
- FreeRTOS multitask scheduling
- CMake-based project build
- STM32F103C8T6 hardware adaption

### Notes
- Basic project documentation and repository metadata were added.
- This version is intended as an initial development baseline.
